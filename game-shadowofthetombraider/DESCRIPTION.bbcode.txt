This extension adds Shadow of the Tomb Raider modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "sottrmodmanager.exe".[/*]
[*]Installs mods with a file or folder named "trreboottools.modmanager.exe".[/*]
[*]Installs mods with a file with one of these extensions: ".dll", ".exe", ".tiger", ".asi" or ".addon64".[/*]
[*]Installs mods with a file with one of these extensions: ".tr11dtp", ".tr11material", ".tr11modeldata", ".t11script", ".t11shaderlib", ".tr11sound", ".dds", ".tr11objectref", ".tr11dtp" or ".tr11anim" to the "Mods" folder.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
