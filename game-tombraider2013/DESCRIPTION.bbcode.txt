This extension adds Tomb Raider (2013) modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "trreboottools.modmanager.exe".[/*]
[*]Installs mods with a file or folder named "texmod.exe".[/*]
[*]Installs mods with a file with the ".tpf" extension to the "TexMod" folder.[/*]
[*]Installs mods with a file with one of these extensions: ".tr9dtp", ".tr9material", ".tr9modeldata", ".t9script", ".t9shaderlib", ".tr9sound", ".dds", ".tr9objectref", ".tr9dtp" or ".tr9anim" to the "Mods" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
