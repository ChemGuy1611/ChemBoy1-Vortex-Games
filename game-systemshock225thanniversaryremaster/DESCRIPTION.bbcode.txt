This extension adds System Shock 2 (Classic AND 25th Anniversary Remaster) modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file with one of these extensions: ".kpf" to the "mods" folder.[/*]
[*]Installs mods with a file or folder named one of: "obj", "mesh", "bitmap", "motions", "sq_scripts", "sdn2", "strings", "iface", "intrface", "misdml" or "snd" and a file with one of these extensions: ".dml", ".gam" or ".mis" to the "mods" folder.[/*]
[*]Installs mods with a file or folder named one of: "mods" or "cutscenes".[/*]
[*]Installs mods with a "mods" folder to the game folder itself (no subfolder).[/*]
[*]Systemshock2 Classicmod mods are recognised by the Systemshock2 Classicmod installer.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
