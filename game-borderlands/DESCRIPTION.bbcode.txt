This extension adds Borderlands modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs TFC Installer itself, recognised by a "tfcinstaller.exe" file.[/*]
[*]Installs UPK Explorer itself, recognised by a "upk explorer.exe" file.[/*]
[*]Installs mods with a "gameprofile.xml" file or a ".packagepatch" file.[/*]
[*]Installs mods with a file or folder named "unrealsdk.dll" and a file or folder named "sdk_mods".[/*]
[*]Installs mods with a file with the ".py" extension and a file with the ".sdkmod" extension.[/*]
[*]Installs mods with a "WillowGame" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a "DLC" folder or a ".upk" file.[/*]
[*]Installs mods with a ".bik" file.[/*]
[*]Installs mods with a "Borderlands.exe" file or a ".dll" file.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
