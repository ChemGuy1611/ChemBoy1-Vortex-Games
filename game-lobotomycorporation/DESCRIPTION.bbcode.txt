This extension adds Lobotomy Corporation modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]The BaseMod loader is downloaded and installed automatically the first time you manage the game, and is kept up to date from its official releases.[/*]
[*]Installs mods with a folder named one of: "Info", "Creature", "Equipment", "Localize", or with a loose ".dll" file, to the "LobotomyCorp_Data\BaseMods" folder.[/*]
[*]Each mod gets its own folder named after the mod archive, which is what the Lobotomy Mod Manager does as well, so mods keep the same load order entry in either tool.[/*]
[*]Mods packed inside an extra wrapper folder are flattened automatically.[/*]
[*]A mod that includes an "Info" folder is given the name it declares there, so the mod list shows the name the mod author chose.[/*]
[*]Installs mods with a folder named "LobotomyCorp_Data" to the game folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]Use the Load Order page to set the order mods load in, and to enable or disable them.[/*]
[*]The load order is written to "BaseModList_v2.xml" in the mods folder. That is the same file the Lobotomy Mod Manager uses, so both tools show the same order and the same enabled mods.[/*]
[*]Mod folders added by hand, without an entry in that file, load after everything else and are always enabled. They appear at the bottom of the Load Order page.[/*]
[*]Unchecking a mod leaves its files installed and tells the loader to skip it.[/*]
[*]Installing the loader replaces the game's "Assembly-CSharp.dll". Vortex backs the original up and restores it when you purge, so you can return the game to an unmodded state at any time.[/*]
[*]The Lobotomy Mod Manager is downloaded once from its Nexus Mods page so the page gets the download credit. That copy is not installed and is not needed - the loader itself is installed from its newer official release.[/*]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
