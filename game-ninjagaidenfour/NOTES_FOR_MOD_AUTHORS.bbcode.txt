[b][color=#e69138][size=4]Notes for Mod Authors - NINJA GAIDEN 4[/size]
[/color][/b]Packaging rules for NINJA GAIDEN 4 mods, so Vortex installs them to the right place.

Vortex decides what a mod is by looking at the files and folders inside the archive. It tries each installer in order and the first one that matches wins, so archive layout is what determines where your mod ends up.

========================================================================

Root / Game Folder Mods:

For mods laid out the same way the files appear inside the game folder. Vortex copies the matched folder and everything under it straight into the game.

[code]
MyRootMod.zip
└── assets\
    └── ... files in their real relative locations
[/code]

  Requirements:
    - Recognised by a folder named "assets", "blob", "config", "fonts", "shaders", "textures" or "truetypefonts" in the archive.

  Installs to: the game folder itself (no subfolder)

  Common mistakes:
    - Zipping the folder that CONTAINS the game folders, instead of the game folders themselves, adds an extra level and misplaces every file.

========================================================================

Asset:

Recognised when the archive contains a file with one of these extensions: ".dat" and a file or folder named one of: "config", "movies" or "sounds".

  Installs to: "Assets"

========================================================================

Rules That Apply To Every Mod Type:

    - Archives containing a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to the built-in FOMOD installer instead.
    - Folder and file name matching is case-insensitive.
    - Extra wrapper folders around a recognised folder are generally fine.
