This extension adds S.T.A.L.K.E.R. 2: Heart of Chornobyl modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "simple_mod_merger.exe" to the "Stalker2SimpleModMerger" folder.[/*]
[*]Installs mods with both a "Content" and a "Binaries" folder to the "Stalker2" folder.[/*]
[*]Installs mods with a "LogicMods" folder to the "Stalker2\Content\Paks\LogicMods\LogicMods" folder.[/*]
[*]Installs mods with a file or folder named "GameLite" to the "Stalker2\Content" folder.[/*]
[*]Installs mods with a file or folder named one of: "NewContent" or "OverrrideContent" to the "Stalker2\Content\Paks\~mods" folder.[/*]
[*]Installs mods with a "dwmapi.dll" file.[/*]
[*]Installs mods with a ".lua" file and a "Scripts" folder.[/*]
[*]Installs mods with a ".dll" file and a "dlls" folder.[/*]
[*]Installs mods with a top-level folder such as "Stalker2" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a config file such as "engine.ini" or "game.ini".[/*]
[*]Installs mods with a ".sav" file.[/*]
[*]Installs mods with anything unrecognised with no pak file.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
