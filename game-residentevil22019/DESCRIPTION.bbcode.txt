This extension adds Resident Evil 2 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs Fluffy Mod Manager itself, recognised by a "modmanager.exe" file.[/*]
[*]Installs REFramework itself, recognised by a "dinput8.dll" file.[/*]
[*]Installs mods with a ".lua" file outside the REFramework folders to the game folder itself (no subfolder).[/*]
[*]Installs mods with a "nvngx_dlss.dll" file or a ".exe" file to the game folder itself (no subfolder).[/*]
[*]Installs mods with a ".prt" file.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
