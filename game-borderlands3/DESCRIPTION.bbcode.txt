This extension adds Borderlands 3 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "openhotfixloader.dll" and a file or folder named "b3hm.exe" to the "OakGame\Binaries\Win64\Plugins" folder.[/*]
[*]Installs mods with a file or folder named "unrealsdk.dll" and a file or folder named "sdk_mods" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with the ".py" extension and a file with the ".sdkmod" extension to the "sdk_mods" folder.[/*]
[*]Installs mods with a file or folder named "d3d11.dll" to the "OakGame\Binaries\Win64" folder.[/*]
[*]Installs mods with a file with the ".bl3hotfix" extension to the "OakGame\Binaries\Win64\Plugins\ohl-mods" folder.[/*]
[*]Installs mods with an "OakGame" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with the ".pak" extension to the "OakGame\Content\Paks" folder.[/*]
[*]Installs mods with a file with the ".mp4" extension to the "OakGame\Content\Movies" folder.[/*]
[*]Binaries mods are installed to the "OakGame\Binaries\Win64" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
