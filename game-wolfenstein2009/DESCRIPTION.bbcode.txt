This extension adds Wolfenstein (2009) modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "base", a file or folder named "SP" and a file or folder named "MP".[/*]
[*]Installs mods with a file or folder named "maps", a file or folder named "SP" and a file or folder named "MP".[/*]
[*]Installs mods with a file or folder named "streampacks", a file or folder named "SP" and a file or folder named "MP".[/*]
[*]Installs mods with a file or folder named "videos", a file or folder named "SP" and a file or folder named "MP".[/*]
[*]Installs mods with a file or folder named "SP", a file or folder named "MP" and a file with the ".pk4" extension.[/*]
[*]Installs mods with a file or folder named "SP", a file or folder named "MP" and a file with the ".exe" extension.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
