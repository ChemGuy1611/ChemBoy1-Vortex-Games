This extension adds TEKKEN 8 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with both a "Content" and a "Binaries" folder to the "Polaris" folder.[/*]
[*]Installs mods with a ".pak" file to the "Polaris\Content\Paks\~mods" folder.[/*]
[*]Installs mods with a top-level folder such as "Polaris", "Engine" or "Content" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a config file such as "engine.ini" or "game.ini".[/*]
[*]Installs mods with a ".sav" file.[/*]
[*]Installs mods with anything unrecognised with no pak file to the "Polaris\Binaries\Win64" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
