This extension adds Vampire: The Masquerade - Bloodlines 2 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with both a "Content" and a "Binaries" folder to the "Bloodlines2" folder.[/*]
[*]Installs mods with a "LogicMods" folder to the "Bloodlines2\Content\Paks\LogicMods\LogicMods" folder.[/*]
[*]Installs mods with a ".pak" file to the "Bloodlines2\Content\Paks\~mods" folder.[/*]
[*]Installs mods with a "dwmapi.dll" file to the "Bloodlines2\Binaries\Win64" folder.[/*]
[*]Installs mods with a ".lua" file and a "Scripts" folder to the "Bloodlines2\Binaries\Win64\ue4ss\Mods" folder.[/*]
[*]Installs mods with a ".dll" file and a "dlls" folder to the "Bloodlines2\Binaries\Win64\ue4ss\Mods" folder.[/*]
[*]Installs mods with a top-level folder such as "Bloodlines2" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file or folder named "Content" to the "Bloodlines2" folder.[/*]
[*]Installs mods with a config file such as "engine.ini" or "game.ini" to the "CONFIGMOD_LOCATION\Bloodlines2" folder.[/*]
[*]Installs mods with a ".sav" file.[/*]
[*]Installs mods with anything unrecognised with no pak file to the "Bloodlines2\Binaries\Win64" folder.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
