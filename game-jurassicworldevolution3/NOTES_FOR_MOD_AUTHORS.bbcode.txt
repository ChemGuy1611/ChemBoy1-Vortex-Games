[b][color=#e69138][size=4]Notes for Mod Authors - Jurassic World Evolution 3[/size]
[/color][/b]Packaging rules for Jurassic World Evolution 3 mods, so Vortex installs them to the right place.

Vortex decides what a mod is by looking at the files and folders inside the archive. It tries each installer in order and the first one that matches wins, so archive layout is what determines where your mod ends up.

========================================================================

ACSE (mod loader):

This installer handles ACSE itself, not mods for it. It exists so users can install ACSE through Vortex, and mod authors normally never package this.

  Requirements:
    - Recognised by a file named "ACSE" in the archive.

  Installs to: "Win64\ovldata"

  Common mistakes:
    - If you bundle ACSE inside your mod archive, Vortex treats the whole download as ACSE rather than as your mod. Ship the mod alone and list ACSE as a requirement.

========================================================================

Root / Game Folder Mods:

For mods laid out the same way the files appear inside the game folder. Vortex copies the matched folder and everything under it straight into the game.

[code]
MyRootMod.zip
└── Win64\
    └── ... files in their real relative locations
[/code]

  Requirements:
    - Recognised by a folder named "Win64", "Blueprints", "Islands", "TerrainSkirts" or "Movies" in the archive.

  Installs to: the game folder itself (no subfolder)

  Common mistakes:
    - Zipping the folder that CONTAINS the game folders, instead of the game folders themselves, adds an extra level and misplaces every file.

========================================================================

ACSE Mods:

Lua mods that run under ACSE.

  Requirements:
    - Recognised by any file named "Main.ovl".

  Installs to: "Win64\ovldata"

  Common mistakes:
    - The archive must contain "Main.ovl" - ACSE identifies mods by that file.

========================================================================

Localised:

Recognised when the archive contains a file or folder named "localised".

  Installs to: "Win64\ovldata\ACSE"

========================================================================

Movie / Cutscene Replacements:

Replacement video files, deployed into the game's movies folder.

  Requirements:
    - Recognised by any file with the ".webm" extension.

  Installs to: "Movies"

  Common mistakes:
    - The replacement must keep the original file name, or the game will not pick it up.

========================================================================

OVL Data Mods:

Packed Cobra Engine content.

  Requirements:
    - Recognised by any file named "ovldata".

  Installs to: "Win64"

========================================================================

Save Game Files:

Save files, deployed to the game's save folder.

  Requirements:
    - Recognised by any file with the ".blpr2" or ".prk2" extensions.

  Installs to: "USER_HOME\Saved Games\Frontier Developments\Jurassic World Evolution 3\USERID_FOLDER\Saves"

  Common mistakes:
    - Including an example save alongside a normal mod makes the archive install as a save.

========================================================================

Rules That Apply To Every Mod Type:

    - Folder and file name matching is case-insensitive.
    - Extra wrapper folders around a recognised folder are generally fine.
