This extension adds Red Dead Redemption modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "dinput8.dll" and a file or folder named "scripthookrdr.dll".[/*]
[*]Installs mods with a file or folder named "kml.asi".[/*]
[*]Magicrdr mods are recognised by the Magicrdr installer.[/*]
[*]Installs mods with a file with one of these extensions: ".wtd", ".was", ".dds", ".mtl" or ".wsc" to the "MagicRDR_Mods" folder.[/*]
[*]Installs mods with a file with the ".rpf" extension to the "kml\rpf" folder.[/*]
[*]Installs mods with a file with the ".asi" extension.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
