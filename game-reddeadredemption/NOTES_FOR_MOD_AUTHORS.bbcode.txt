[b][color=#e69138][size=4]Notes for Mod Authors - Red Dead Redemption[/size]
[/color][/b]Packaging rules for Red Dead Redemption mods, so Vortex installs them to the right place.

Vortex decides what a mod is by looking at the files and folders inside the archive. It tries each installer in order and the first one that matches wins, so archive layout is what determines where your mod ends up.

========================================================================

Scripthook:

Recognised when the archive contains a file or folder named "dinput8.dll" and a file or folder named "scripthookrdr.dll".

========================================================================

Modloader:

Recognised when the archive contains a file or folder named "kml.asi".

========================================================================

Magicmod:

Recognised when the archive contains a file with one of these extensions: ".wtd", ".was", ".dds", ".mtl" or ".wsc".

  Installs to: "MagicRDR_Mods"

========================================================================

Magicrdr:

Recognised when the archive contains a file or folder named "MagicRDR.exe".

========================================================================

Rpf:

Recognised when the archive contains a file with the ".rpf" extension.

  Installs to: "kml\rpf"

========================================================================

Asiplugin:

Recognised when the archive contains a file with the ".asi" extension.

========================================================================

Rules That Apply To Every Mod Type:

    - Archives containing a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to the built-in FOMOD installer instead.
    - Folder and file name matching is case-insensitive.
    - Extra wrapper folders around a recognised folder are generally fine.
