This extension adds Watch_Dogs modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Ubisoft Connect[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "ModManager.exe" and a file or folder named "bin".[/*]
[*]Installs mods with a file with one of these extensions: ".dat" or ".fat" to the "data_win64\mods" folder.[/*]
[*]Installs mods with a "data_win64" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with one of these extensions: ".exe", ".dll", ".asi" or ".addon64".[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
