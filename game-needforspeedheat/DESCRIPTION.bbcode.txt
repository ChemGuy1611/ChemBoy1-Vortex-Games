This extension adds Need for Speed Heat modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs Frosty Mod Manager itself, recognised by a "frostymodmanager.exe" file.[/*]
[*]Installs mods with a ".fbmod" file to the "FrostyModManager\Mods\NeedForSpeedHeat" folder.[/*]
[*]Installs mods with a file with the ".exe" extension and a file with one of these extensions: ".dll" to the "FrostyModManager\Plugins" folder.[/*]
[*]Key mods are installed to the "FrostyModManager" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
