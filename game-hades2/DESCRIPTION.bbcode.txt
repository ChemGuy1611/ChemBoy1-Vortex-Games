This extension adds Hades II modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "modimporter.exe" to the "Content" folder.[/*]
[*]Installs mods with a file or folder named "modutil.lua" and a file or folder named "main.lua" to the "Content\Mods\ModUtil" folder.[/*]
[*]Installs mods with a file or folder named "d3d12.dll".[/*]
[*]Installs mods with a file or folder named "manifest.json", a file or folder named "main.lua" and a file or folder named "d3d12.dll".[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
