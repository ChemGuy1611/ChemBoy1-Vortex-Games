# Changelog

## Planned Improvements (Not Yet Released)

- Fixed: Mod files whose names only begin with README, CHANGELOG, or LICENSE (for example, License_Plates.dds) are no longer skipped during deployment.
- Added: README and CHANGELOG files spelled with a hyphen, underscore, or space (for example, READ_ME.txt or Change Log.md) are now excluded from mod conflict detection and deployment.

## [0.4.1] - 2026-11-04

- Changed: Browse pages no longer open ads and other pop-ups in your web browser. A blocked page shows a notification with an "Open" button instead.

## [0.4.0] - 2026-11-03

- Added: Discovery and launch support for the Xbox version of Metro Exodus Enhanced Edition.

## [0.3.0] - 2026-11-01

- Added: Installer and mod type for Exodus SDK mods. Each installs into its own folder in "SDKMods", ready to pick with "Add Existing Mod" in the Exodus SDK launcher.
- Added: "Browse mod.io" page to browse the game's mods on mod.io and install them directly in Vortex, with update checks and dependency installs, plus an "Open mod.io Page" button.

## [0.2.3] - 2026-10-25

- Added the Nexus mod ID to the extension info.

## [0.2.2] - 2026-10-16

- Added the game's Nexus Mods ID to the extension's info file.

## [0.2.1] - 2026-10-02

- Added support for the Xbox / Microsoft Store version of the game.
- Added an "Open SteamDB Page" button next to the PCGamingWiki one.
- The various "Open X Folder"/"Open X Page" buttons now show an error message if the folder or page can't be opened, instead of failing silently.

## [0.2.0] - 2026-08-03

- Fixed: Readme and changelog files inside mods no longer show up as file conflicts.
- Fixed: Paths are now built safely on all systems.
- Added: Buttons to open the game's PCGamingWiki page, view the changelog, submit a bug report, and open the downloads folder.

## [0.1.2]

- Initial release
