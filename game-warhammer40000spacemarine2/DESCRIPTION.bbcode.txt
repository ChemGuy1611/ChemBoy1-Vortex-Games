This extension adds WH40K Space Marine 2 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "IntegrationStudio.exe" to the "client_pc\root" folder.[/*]
[*]Installs mods with a file with one of these extensions: ".pak" to the "client_pc\root\mods" folder.[/*]
[*]Installs mods with a "client_pc" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file or folder named "local" to the "client_pc\root" folder.[/*]
[*]Installs mods with a file or folder named one of: "ssl", "video", "textures", "presets", "texts" or "ui" to the "client_pc\root\local" folder.[/*]
[*]Binaries mods are installed to the "client_pc\root\bin\pc" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
