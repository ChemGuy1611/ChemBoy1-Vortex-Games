This extension adds Warhammer 40,000: Dark Heresy modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "MicroPatches.dll" to the "MICROPATCHES_PATH" folder.[/*]
[*]Modfinder mods are recognised by the Modfinder installer.[/*]
[*]Saveeditor mods are recognised by the Saveeditor installer.[/*]
[*]Portraitmanager mods are recognised by the Portraitmanager installer.[/*]
[*]Installs mods with a file or folder named one of: "owlcatmodificationmanifest.json", a file or folder named one of: "Assemblies", "Blueprints", "Bundles" or "Localization" and a file with one of these extensions: ".dll" to the "USER_HOME\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\Modifications" folder.[/*]
[*]Installs mods with a file with one of these extensions: ".dll" to the "USER_HOME\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\UnityModManager" folder.[/*]
[*]Installs mods with a file or folder named one of: "fulllength.png", "medium.png" or "small.png" to the "USER_HOME\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\Portraits" folder.[/*]
[*]Installs mods with a ".zks" file to the "USER_HOME\AppData\LocalLow\Owlcat Games\Warhammer 40000 Rogue Trader\Saved Games" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
