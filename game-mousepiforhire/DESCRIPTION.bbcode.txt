This extension adds MOUSE: P.I. For Hire modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs BepInEx itself to the game folder itself (no subfolder), recognised by a "winhttp.dll" file.[/*]
[*]Installs mods with a file or folder named "winhttp.dll" and a file or folder named "doorstop_config.ini" to the game folder itself (no subfolder).[/*]
[*]Installs MelonLoader itself to the game folder itself (no subfolder), recognised by a "version.dll" file.[/*]
[*]Installs mods with a "MOUSE_Data" folder to the game folder itself (no subfolder).[/*]
[*]Installs BepInEx Configuration Manager itself to the "BepInEx" folder, recognised by a "configurationmanager.dll" file.[/*]
[*]Installs MelonLoader Preferences Manager itself to the "Mods" folder, recognised by a "melonprefmanager.mono.dll" file.[/*]
[*]Installs mods with a "GameAssembly.dll" file to the game folder itself (no subfolder).[/*]
[*]Installs mods with a ".dll" file to the "BepInEx" folder.[/*]
[*]Installs mods with a ".assets" file to the "MOUSE_Data" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
