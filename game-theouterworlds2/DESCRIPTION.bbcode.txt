This extension adds The Outer Worlds 2 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with both a "Content" and a "Binaries" folder to the "Arkansas" folder.[/*]
[*]Installs mods with a "LogicMods" folder to the "Arkansas\Content\Paks\LogicMods\LogicMods" folder.[/*]
[*]Installs mods with a ".pak" file to the "Arkansas\Content\Paks\~mods" folder.[/*]
[*]Installs mods with a "dwmapi.dll" file.[/*]
[*]Installs mods with a ".lua" file and a "Scripts" folder.[/*]
[*]Installs mods with a ".dll" file and a "dlls" folder.[/*]
[*]Installs mods with a top-level folder such as "Arkansas" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file or folder named "Content" to the "Arkansas" folder.[/*]
[*]Installs mods with a config file such as "engine.ini" or "game.ini".[/*]
[*]Installs mods with a ".sav" file.[/*]
[*]Installs mods with anything unrecognised with no pak file.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
