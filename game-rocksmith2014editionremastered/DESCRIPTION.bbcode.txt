This extension adds Rocksmith 2014 Edition REMASTERED modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a "base" folder or a "cache.psarc" file to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with the ".psarc" extension to the "dlc" folder.[/*]
[*]Installs mods with a file or folder named "eof.exe" to the "EditorOnFire" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
