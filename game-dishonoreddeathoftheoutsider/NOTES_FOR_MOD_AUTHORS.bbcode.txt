[b][color=#e69138][size=4]Notes for Mod Authors - Dishonored: Death of the Outsider[/size]
[/color][/b]Packaging rules for Dishonored: Death of the Outsider mods, so Vortex installs them to the right place.

Vortex decides what a mod is by looking at the files and folders inside the archive. It tries each installer in order and the first one that matches wins, so archive layout is what determines where your mod ends up.

========================================================================

Voidinstaller:

Recognised when the archive contains a file or folder named "voidinstaller.exe".

  Installs to: the game folder itself (no subfolder)

========================================================================

Voidexplorer:

Recognised when the archive contains a file or folder named "voidexplorer.exe".

  Installs to: the game folder itself (no subfolder)

========================================================================

Voidmod:

Recognised when the archive contains a file or folder named "modinfo.xml" and a file with one of these extensions: ".voidindex" or ".voidresources".

  Installs to: "Void Installer\Mods"

========================================================================

Root / Game Folder Mods:

For mods laid out the same way the files appear inside the game folder. Vortex copies the matched folder and everything under it straight into the game.

[code]
MyRootMod.zip
└── base\
    └── ... files in their real relative locations
[/code]

  Requirements:
    - Recognised by a folder named "base" in the archive.

  Installs to: the game folder itself (no subfolder)

  Common mistakes:
    - Zipping the folder that CONTAINS the game folders, instead of the game folders themselves, adds an extra level and misplaces every file.

========================================================================

Video:

Recognised when the archive contains a file with one of these extensions: ".bk2".

  Installs to: "base\video"

========================================================================

Save Game Files:

Save files, deployed to the game's save folder.

  Requirements:
    - Recognised by any file with the ".sav" extension.

  Common mistakes:
    - Including an example save alongside a normal mod makes the archive install as a save.

========================================================================

Config File Mods:

Configuration tweaks, deployed to the game's config location.

  Requirements:
    - Recognised by any file named "dishonored_doconfig.cfg".

  Installs to: "USERHOME\Saved Games\Arkane Studios\Dishonored_DO\base"

  Common mistakes:
    - Shipping a config file with one of these names inside an unrelated mod makes the whole archive install as a config mod.

========================================================================

Rules That Apply To Every Mod Type:

    - Folder and file name matching is case-insensitive.
    - Extra wrapper folders around a recognised folder are generally fine.
