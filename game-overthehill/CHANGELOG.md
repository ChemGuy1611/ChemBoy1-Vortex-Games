# Changelog

## Planned Improvements (Not Yet Released)

- Fixed: Mod files whose names only begin with README, CHANGELOG, or LICENSE (for example, License_Plates.dds) are no longer skipped during deployment.
- Added: README and CHANGELOG files spelled with a hyphen, underscore, or space (for example, READ_ME.txt or Change Log.md) are now excluded from mod conflict detection and deployment.

## [1.2.1] - 2026-11-04

- Changed: Browse pages no longer open ads and other pop-ups in your web browser. A blocked page shows a notification with an "Open" button instead.

## [1.2.0] - 2026-11-01

- Added: Installer and mod type for vehicle livery packs. They install into "Documents/My Games/over the hill/LocalLiveries", and need the game and Vortex staging folder on the same drive as Documents.
- Added: "Browse mod.io" page to browse the game's mods on mod.io and install them directly in Vortex, with update checks and dependency installs, plus an "Open mod.io Page" button.
- Changed: manifest.json and icon.png files are no longer skipped during deployment.

## [1.1.0] - 2026-10-29

- Added: GOG version support.

## [1.0.0] - 2026-10-17

- Initial release
