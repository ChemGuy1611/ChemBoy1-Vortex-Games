This extension adds Crimson Desert modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a "bin64" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with the ".exe" extension.[/*]
[*]Installs mods with a file or folder named one of: "//DMM_EXEC", "CD JSON Mod Manager.exe", "CrimsonSharp.exe", "CrimsonSaveEditorStandalone.exe", "PazGui.exe", "CDModManager.exe", "QT_ModManager.exe" or "CrimsonDesertModManager.exe".[/*]
[*]Installs mods with a file with the ".exe" extension and a file with one of these extensions: ".dll", ".asi" or ".addon64".[/*]
[*]Installs mods with a file or folder named "manifest.json", a file or folder named "files" and a file or folder named one of: "meta", "0000", "0001", "0002", "0003", "0004", "0005", "0006", "0007", "0008", "0009", "0010", "0011", "0012", "0013", "0014", "0015", "0016", "0017", "0018", "0019", "0020", "0021", "0022", "0023", "0024", "0025", "0026", "0027", "0028", "0029", "0030", "0031", "0032", "0033", "0034", "0035", "//'0036'", "//this folder is used by patch mods" or "so we don't want to put it in root" to the "mods" folder.[/*]
[*]Installs mods with a file or folder named one of: "modinfo.json" to the "mods" folder.[/*]
[*]Installs mods with a file or folder named one of: "meta", "0000", "0001", "0002", "0003", "0004", "0005", "0006", "0007", "0008", "0009", "0010", "0011", "0012", "0013", "0014", "0015", "0016", "0017", "0018", "0019", "0020", "0021", "0022", "0023", "0024", "0025", "0026", "0027", "0028", "0029", "0030", "0031", "0032", "0033", "0034", "0035", "//'0036'", "//this folder is used by patch mods" or "so we don't want to put it in root" and a file with one of these extensions: ".dds".[/*]
[*]Installs mods with a file with the ".json" extension and a file or folder named one of: "modinfo.json".[/*]
[*]Installs mods with a file with the ".exe" extension and a file with one of these extensions: ".dll", ".asi" or ".addon64" to the "bin64" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
