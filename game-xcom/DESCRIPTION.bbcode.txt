This extension adds XCOM: Enemy Unknown modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs TFC Installer itself to the game folder itself (no subfolder), recognised by a "tfcinstaller.exe" file.[/*]
[*]Installs UPK Explorer itself to the game folder itself (no subfolder), recognised by a "upk explorer.exe" file.[/*]
[*]Installs mods with a "gameprofile.xml" file or a ".packagepatch" file to the "TFCInstaller\Mods" folder.[/*]
[*]Installs mods with an "Engine" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a "Maps" folder or a ".upk" file to the "XXX\CookedPC" folder.[/*]
[*]Installs mods with a ".bik" file to the "XXX\Movies" folder.[/*]
[*]Installs mods with a "XXX.exe" file or a ".exe" file to the "Binaries\Win32" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
