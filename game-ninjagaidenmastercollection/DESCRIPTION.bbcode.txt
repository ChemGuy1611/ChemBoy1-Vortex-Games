This extension adds NINJA GAIDEN: Master Collection modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "tmx_ngloader.exe".[/*]
[*]Installs mods with a file or folder named "ninja gaiden sigma.exe".[/*]
[*]Installs mods with a file or folder named "ninja gaiden sigma2.exe".[/*]
[*]Installs mods with a file or folder named "ninja gaiden 3 razor's edge.exe".[/*]
[*]Installs mods with a file with the ".dat" extension to the "mods" folder.[/*]
[*]Installs mods with a file or folder named "databin".[/*]
[*]Installs mods with a file or folder named one of: "bgm" or "movie" to the "databin" folder.[/*]
[*]Installs mods with a file or folder named one of: "sound" or "movie".[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
