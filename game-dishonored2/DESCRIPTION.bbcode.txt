This extension adds Dishonored 2 modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]GOG[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "voidinstaller.exe" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file or folder named "voidexplorer.exe" to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file or folder named "modinfo.xml" and a file with one of these extensions: ".voidindex" or ".voidresources" to the "Void Installer\Mods" folder.[/*]
[*]Installs mods with a "base" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with one of these extensions: ".bk2" to the "base\video" folder.[/*]
[*]Installs mods with a ".sav" file.[/*]
[*]Installs mods with a "dishonored2config.cfg" file to the "USERHOME\Saved Games\Arkane Studios\Dishonored2\base" folder.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
