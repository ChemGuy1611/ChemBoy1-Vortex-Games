This extension adds Dying Light The Beast modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Mergerutility mods are installed to the "ph_ft" folder.[/*]
[*]Supermerger mods are installed to the "ph_ft" folder.[/*]
[*]Installs mods with a file with the ".pak" extension to the "ph_ft\mods" folder.[/*]
[*]Installs mods with a "ph_ft" folder to the game folder itself (no subfolder).[/*]
[*]Installs mods with a file with the ".pak" extension to the "ph_ft\work\bin\x64" folder.[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
