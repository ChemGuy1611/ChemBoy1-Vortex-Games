[b][color=#e69138][size=4]Notes for Mod Authors - template-rpgmaker (template)[/size]
[/color][/b]Packaging rules for template-rpgmaker (template) mods, so Vortex installs them to the right place.

Vortex decides what a mod is by looking at the files and folders inside the archive. It tries each installer in order and the first one that matches wins, so archive layout is what determines where your mod ends up.

========================================================================

XXX Jsfolder:

Recognised when the archive contains a file or folder named "js".

  Installs to: the game folder itself (no subfolder)

========================================================================

XXX Jsfile:

Recognised when the archive contains a file with the ".js" extension.

  Installs to: "js\plugins"

========================================================================

Root / Game Folder Mods:

For mods laid out the same way the files appear inside the game folder. Vortex copies the matched folder and everything under it straight into the game.

[code]
MyRootMod.zip
└── audio\
    └── ... files in their real relative locations
[/code]

  Requirements:
    - Recognised by a folder named "audio", "css", "data", "effects", "fonts", "icon", "img", "lib", "locales" or "swiftshader" in the archive.

  Installs to: the game folder itself (no subfolder)

  Common mistakes:
    - Zipping the folder that CONTAINS the game folders, instead of the game folders themselves, adds an extra level and misplaces every file.

========================================================================

XXX Json:

Recognised when the archive contains a file with the ".json" extension.

  Installs to: "data"

========================================================================

Fallback Installer:

The catch-all. Any archive that matched none of the installers above lands here and is copied across unchanged.

[b][color=#ffff00]NOTE: Landing in the fallback installer is a signal your archive layout needs fixing.[/color][/b]

  Requirements:
    - Reaching this installer usually means the archive was not laid out in a way Vortex recognised.
    - Vortex shows the user a notification when a mod installs through the fallback.

  Common mistakes:
    - If your mod lands here unintentionally, re-check the layouts above - users will see a fallback warning and may report the mod as broken.

========================================================================

Rules That Apply To Every Mod Type:

    - Archives containing a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to the built-in FOMOD installer instead.
    - Folder and file name matching is case-insensitive.
    - Extra wrapper folders around a recognised folder are generally fine.
