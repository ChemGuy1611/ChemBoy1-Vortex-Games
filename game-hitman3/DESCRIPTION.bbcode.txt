This extension adds HITMAN World of Assassination modding support to Vortex Mod Manager.

[b]✅ Supported Versions:[/b]
[list]
[*]Steam[/*]
[*]Epic[/*]
[*]Xbox (Game Pass)[/*]
[*]Other versions may need to select the installation location manually.[/*]
[/list]
[b]🛠️ Mod Installation Notes:[/b]
[list]
[*]Installs mods with a file or folder named "Deploy.exe".[/*]
[*]Installs mods with a file or folder named one of: "manifest.json" and a file with one of these extensions: ".rpkg" to the "Vortex_Mods" folder.[/*]
[*]Any other mod not described above is installed to the game folder itself (no subfolder).[/*]
[*]Archives with a FOMOD installer (a "fomod" folder with ModuleConfig.xml) are handed to Vortex's built-in FOMOD installer instead.[/*]
[/list]
[b]📋 Usage Notes:[/b]
[list]
[*]Deploying only places each mod in the "Vortex_Mods" folder. Simple Mod Framework still has to install them before they do anything in game.[/*]
[*]Open Simple Mod Framework, press its "Add a Mod" button and pick the archive for the mod you want. The framework unpacks it and adds it to its own mod list, where you can enable it and set the load order.[/*]
[*]The notification shown after deploying has buttons to launch Simple Mod Framework and to open the "Vortex_Mods" folder. Both are also on the Mods toolbar.[/*]
[*]Leave Simple Mod Framework's own "Mods" folder alone. The framework reads every entry in it as a mod, so adding files there by hand stops it from starting.[/*]
[*]Simple Mod Framework's installer is downloaded once from its Nexus Mods page so the page gets the download credit. It is not run, and it is not needed - the framework itself is installed from its official release.[/*]
[*]You can open several useful files/folders/URLs using the buttons within the folder icon on the Mods toolbar.[/*]
[/list]
